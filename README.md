# 404 Gadgets Store

A responsive online store for phones, tablets, and accessories, developed by Team 404 Found. This repository is my portfolio copy of the team project.

My contributions include light and dark themes, product cards, homepage product sections, product details, and adapting background and button effects from React Bits.

## Live Preview

[View Live Demo](https://artmay777.github.io/404-gadgets-store/)

## Technologies Used

- React
- TypeScript
- React Router
- SCSS Modules
- Swiper
- Vite

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/ArtMay777/404-gadgets-store.git
cd 404-gadgets-store
```

### 2. Install dependencies

```bash
npm install
```

### 3. Run the project locally

```bash
npm start
```

## Features

- Product catalog with search, filtering, sorting, and pagination
- Product details with an image gallery, color and storage selection
- Shopping cart, favorites, and product comparison
- Light and dark themes
- Responsive layout
- Animations and sound effects
